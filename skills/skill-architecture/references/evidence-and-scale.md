# 证据与变更尺度

## 证据强度要匹配机制类型
- **强机制**——持久状态、中央共享层、validator、权限门、兼容层、状态机、多 Skill 流程、强制调查过程——需要强证据：真实事故、外部契约、机器消费者、权限或不可逆副作用、确定性状态问题。
- **判断辅助**——提示、领域经验、reference、流程引导——是否改善专业判断需要行为证据，文档完整性与理论自洽不算。但其中的契约冲突、消费者错配或可复现误判可以独立裁决，不必等行为对照才修正。
- **低成本、可逆、不侵吞判断的初始假设**可以先试；但要有观察方式和放弃条件，否则它会变成下一件无证据的永久机制。

举证责任沿四个维度上升：持久性、对模型自由的限制、状态面与兼容面的扩张、跨 Skill 的共享程度。

## 裁决强度
这三等描述的是结论的可推导性，不是证据的种类，也不决定改动尺度。结论应标明自己属于哪一等，三等不能互相冒充：

- **可以裁决**：材料本身构成证据，结论不依赖模型行为。要写明是哪个结构事实支撑了它。
- **很可能，需确认**：材料强烈指向某个结构，但存在未读的消费路径或外部使用者。结论要带上确认方式。
- **只能标记为需要行为验证**：结论取决于模型在真实运行中的表现，材料无法替代。

第三等不写成已证实的收益。可以基于明确契约缺陷进行修正，同时把真实任务效果保留为未验证，不因此强制启动新的评测或优化流程。例如已复现体验表误拒、验收关键词误判，并清理冗余契约，不等于已证明减法后模型诊断更深或任务质量更高。

把第二等写成第一等，是最常见的过度裁决；把第一等推给第三等，则是用谨慎代替判断。两者都使报告失去可用性。

## 变更尺度
根因在单点，就做单点修正；根因在模型、边界或知识架构，就允许合并、拆分、重建或完整切换。两种错误对称：大改可以掩盖尚未定位的根因，小改可以回避已经清楚的结构事实。

判断依据只有根因范围，不是改动成本，不是「重构更彻底」，也不是「小改更安全」。

「保持」是真实结论，需要与「重构」同等强度的论证：说明哪些复杂性在承担真实负担，以及为什么现有证据不足以承担改动风险。反过来，当结构事实已经清楚时，「改动风险」不能成为保留错误结构的理由。

最常见的尺度错误是默认追加结构。根因来自旧约束本身时，删除、合并、收窄或替换可能比补新例外更合适；原有能力与保护仍需有明确去向。是否增加机制与改多少都是结论，不把减法变成另一种固定偏好。

不保留历史兼容。判断要求切换时就彻底切换；确实需要兼容时，必须同时给出对象与退出条件，否则它就是被永久化的迁移成本。

## 张力裁决
- 先识别双方各自保护的价值，而不是判断哪一边更现代。
- 能分层的，用责任分层解决：把冲突放到不同作用域，而不是选一边。
- 无法分层时，交给当前领域事实、真实消费者、失败历史、运行成本与副作用裁决。
- 裁决是局部的，不得自动升级为普遍规则；不同问题域允许得出相反结论。
- 例外只有一个，即 SKILL.md 所说的语义矛盾：同一当前事实的多个权威生产者。除此之外的张力都应长期存在。
